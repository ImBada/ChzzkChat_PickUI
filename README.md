# 치지직 채팅 탄막 오버레이

치지직 라이브 채팅을 니코니코 동화식 탄막으로 OBS 화면 위에 흘려보내는 오버레이입니다. 채팅을 고르는 과정 없이, 채널에 연결된 뒤 들어오는 모든 메시지가 자동으로 오른쪽에서 왼쪽으로 지나갑니다. 현재 시청자 수도 오버레이 좌측 상단에 고정 표시됩니다.

## 화면 구성

| 페이지 | URL | 용도 |
| --- | --- | --- |
| 관리자 | `http://localhost:5173/` | 채널 연결, 채팅 확인, 탄막 설정 |
| 탄막 오버레이 | `http://localhost:5173/display.html` | OBS 브라우저 소스 |

## 시작하기

```bash
npm install
npm run dev
```

Vite 클라이언트는 5173번 포트, Socket.io 서버는 3001번 포트에서 실행됩니다.

프로덕션에서는 다음 명령을 사용합니다.

```bash
npm run build
CHZZK_CONTROL_TOKEN='충분히-긴-임의의-문자열' npm start
```

## 사용 방법

1. 관리자 페이지에 치지직 채널 URL이나 32자리 채널 ID를 입력하고 **연결**을 누릅니다.
2. OBS에서 **소스 추가 → 브라우저**를 선택합니다.
3. URL을 `http://localhost:5173/display.html`, 너비와 높이를 `1920 × 1080`으로 설정합니다.
4. 필요하면 관리자 하단에서 탄막 설정을 조절합니다.

관리자 설정은 연결된 모든 오버레이에 즉시 반영되며, 오버레이를 나중에 열어도 서버에 저장된 현재 설정을 받습니다.

시청자 수는 치지직 웹과 같은 라이브 상태 API를 30초 주기로 갱신합니다. 채팅 WebSocket의 `mbrCnt`는 실제 동시 시청자 수가 아니라서 사용하지 않습니다.

- **통과 시간**: 댓글 하나가 화면을 완전히 가로지르는 시간입니다. 4~30초.
- **크기**: 댓글 글자와 레인 간격의 배율입니다. 0.5~3배.
- **닉 표시**: 댓글 앞에 닉네임을 붙일지 선택합니다.
- **탄막 테스트**: 채널 연결 없이 샘플 댓글을 보내 OBS 배치를 확인합니다.

오버레이 배경은 기본적으로 투명합니다. OBS에서 별도 CSS는 필요하지 않습니다.

## 관리자 제어 보안

`npm run dev`로 실행한 개발 서버는 같은 컴퓨터에서 `localhost`로 직접 접속할 때 별도 설정 없이 관리자 기능을 사용할 수 있습니다. 프로덕션 서버는 접속 위치와 관계없이 관리 토큰이 필요합니다.

```bash
CHZZK_CONTROL_TOKEN='충분히-긴-임의의-문자열' npm start
```

그다음 관리자 화면의 **관리 토큰** 칸에 같은 값을 입력합니다. 토큰을 설정하면 서버가 실행 중인 컴퓨터에서 접속하더라도 모든 연결·해제·설정·미리보기 요청에 토큰이 필요합니다. 원격으로 공개할 때는 토큰 노출을 막기 위해 HTTPS 리버스 프록시 뒤에서 사용하세요.

관리 권한이 없는 클라이언트도 탄막과 연결 상태는 볼 수 있지만 서버를 제어할 수는 없습니다.

## 탄막 배치 방식

화면 높이를 여러 레인으로 나누고, 각 댓글의 길이와 이동 속도를 계산해 앞 댓글을 추월하지 않는 레인에 배치합니다. 모든 레인이 사용 중이면 댓글을 잠시 대기열에 두었다가 안전한 레인이 생기는 즉시 표시합니다. 오래 기다린 긴 댓글에는 전용 레인을 예약하며, 대기열은 최대 150개로 제한됩니다. 이미 기다리는 댓글을 보존하기 위해 포화 상태에서는 새로 들어온 메시지를 건너뜁니다.

치지직 이모티콘도 원본 이미지로 렌더링됩니다.

## 로그인 필요 채널

일반 공개 채널은 쿠키 없이 연결할 수 있습니다. 성인 인증 등이 필요한 채널은 관리자 화면 도움말에 따라 아래 형식의 Naver 로그인 쿠키를 입력합니다.

```text
NID_AUT=xxxxx; NID_SES=yyyyy
```

쿠키는 관리자 브라우저의 `localStorage`에 저장됩니다.

## 주요 구조

```text
server/
  index.ts                         Express + Socket.io 서버
  chzzkClient.ts                   치지직 WebSocket 클라이언트
src/
  admin/                           채널 연결 및 설정 화면
  display/
    App.tsx                        탄막 대기열 및 레인 스케줄러
    components/DanmakuMessage.tsx  움직이는 댓글 렌더러
  shared/
    MessageContent.tsx             치지직 이모티콘 렌더링
    socket.ts                      Socket.io 클라이언트
    types.ts                       공유 타입
```

## Socket.io 이벤트

| 이벤트 | 방향 | 내용 |
| --- | --- | --- |
| `chat:connect` | 관리자 → 서버 | 치지직 채널 연결 |
| `chat:disconnect` | 관리자 → 서버 | 채널 연결 해제 |
| `chat:message` | 서버 → 전체 | 관리자 목록 및 탄막에 실시간 채팅 전달 |
| `viewer:count` | 서버 → 전체 | 현재 시청자 수 전달 |
| `server:status` | 서버 → 전체 | 연결 상태 전달 |
| `display:config` | 양방향 | 통과 시간, 크기, 닉네임 설정 동기화 |
| `display:preview` | 관리자 → 서버 | 샘플 탄막 전송 |
| `control:error` | 서버 → 관리자 | 관리 권한 오류 전달 |
